# 抖音爆款素材雷达（MVP 方案）

一个用于**找出抖音各类产品爆款短视频素材**的系统设计草案，目标是帮助选品、投放和内容团队快速定位可复用的高表现内容模式。

## 核心能力

- **多品类检索**：按类目（美妆、3C、家居、零食等）与关键词组合检索候选视频。
- **爆款识别评分**：基于播放、点赞、评论、转发、完播率（可选）构建综合热度分。
- **素材结构拆解**：自动提取标题文案、封面风格、前 3 秒钩子、口播节奏、镜头模板。
- **可复用模板输出**：按“开场钩子 + 痛点 + 证明 + 行动召唤”输出脚本模板。
- **竞品监控**：跟踪指定品牌/店铺账号近 7/30 天爆款波动。

## 爆款评分建议（可配置）

```text
hot_score = 0.35 * norm(点赞率)
          + 0.25 * norm(评论率)
          + 0.20 * norm(转发率)
          + 0.10 * norm(完播率)
          + 0.10 * norm(近7天增速)
```

> 说明：`norm()` 为分位数标准化，减少不同类目之间量级差异。

## 数据处理流程

1. **采集层**：关键词、话题、达人、商品链接维度获取候选视频元数据。
2. **清洗层**：去重、异常值过滤、发布时间窗口统一。
3. **分析层**：计算互动率、增速、稳定性，并打爆款分。
4. **理解层**：ASR/OCR 抽取文案与字幕，CV 识别镜头与封面元素。
5. **输出层**：素材库检索、榜单、脚本建议、对标报告。

## MVP 页面

- **搜索页**：输入产品词（如“筋膜枪”）+ 价格带 + 人群。
- **榜单页**：近 7/30 天爆款视频 TopN。
- **拆解页**：单条视频结构化解读。
- **模板页**：一键生成可拍摄脚本与镜头清单。

## 技术栈建议

- 后端：Python + FastAPI
- 数据：PostgreSQL（结构化）+ 对象存储（媒体）
- 任务调度：Celery / Airflow
- 前端：Next.js
- 算法：
  - 文本：关键词聚类、情绪/卖点抽取
  - 语音：ASR
  - 图像：封面风格与镜头片段分类

## 合规与风控

- 严格遵守平台条款与数据使用规范。
- 仅用于分析与创意参考，避免侵权搬运。
- 建立素材来源追踪与版权标记机制。

## 迭代路线图

- **V1（2-4 周）**：关键词检索 + 爆款分 + TopN 榜单。
- **V2（4-8 周）**：视频拆解与脚本模板生成。
- **V3（8-12 周）**：自动监控、竞品预警、投放建议。
